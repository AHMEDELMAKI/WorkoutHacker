## Authentication APIs

### **`POST`** `/auth/register`
[cite_start]Register a new user[cite: 8].

**Parameters:**
| Name | Located In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `userType` | query | string | No | Optional user type (default is user). [cite_start]Available values: `user`, `coach`[cite: 11, 13, 14, 15, 16]. |
