This project currently targets Android only.

# Getting Started

## Start Metro

Run the React Native dev server from the project root:

```sh
npm start
```

## Run on Android

With Metro running, open a second terminal and launch the app:

```sh
npm run android
```

You can also build and run the native app directly from Android Studio if you prefer.

## Fast Refresh

Edit `App.tsx` or files under `src/` and save to see updates automatically. To force a reload on Android, press <kbd>R</kbd> twice or open the Dev Menu with <kbd>Ctrl</kbd> + <kbd>M</kbd>.
